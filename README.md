# アスキー文字生成機

##概要
標準入力から受け取った文字列を、「アスキーアートバナー」として標準出力に出力する

##リポジトリのクローン方法
以下のコマンドをターミナル上で実行する。
```
git clone https://github.com/kazu624/robosys2025
```

##実行方法
###asciiについて
プログラム内部に定義されたFONTを使用して、入力された文字一つ一つを5行のブロック状の図形（アスキーアート）にマッピングします。

###実行コード
```
echo "出力したいテキスト" | ./ascii 
```
